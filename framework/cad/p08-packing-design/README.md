## C01：独立套筒概念，不能直接装入旧盖

`P08_PACK_C01_concept.step` 为局部杆、套筒、五个填料环和压盖鼻，共八个实体。局部套筒示意外径 52，上段 z332–362 内孔 44，下段 z322–332 内孔 36.4，肩位 z332。共面接触允许、正体积交叠为零；这只检查八个简化实体，不是全阀装配。

经真实 GA1 全开部件布尔，该套筒与原研究阀盖交叠 **24127.431580 mm³**，故现有 D44 孔装不下 OD52 套筒，不能直接采用。套筒的固定、轴向反力传递、防脱及密封均未设计完成；该版本为历史比较，后续优先研究 C02。局部 D36 柱体在 z322–380 与 GA1 全开杆公共体积 59036.809146 mm³，差异约 -2.6×10⁻⁹ mm³（数值舍入）；这只是局部柱体覆盖关系，非全杆等同或全行程检查。图中 D52 是局部包络。

## C02：阀盖一体台肩候选

从 GA1 A05 全开研究阀盖开始，在 z322–332、r18.2–22 增加环形材料形成一体台肩；z332 以上保持 D44 填料函孔，肩下 D36.4 孔与名义 D36 杆之间径向余量 0.2。压盖鼻与杆径向余量 0.2、与填料函孔径向余量 0.1。`P08_PACK_C02_section.svg` / `.dxf` 是局部轴向概念剖面，盖体只画到局部外径 52 以便识图，并不表示阀盖实际外径。

台肩体积 4799.096938 mm³；与原盖的正体积交叠为零，融合后为一个有效 CAD 实体，STEP 回读有效。仅在 GA1 全开单姿态下，修改盖与 GA1 杆、压盖和五个填料环的正体积交叠均为零。这不证明接触力、强度、整阀适配、公差或连续装拆。D40 杆头不能从 D36.4 肩孔穿过，必须设计和核验从下方装杆等可行的装拆序列，不能假定可安装。台肩、阀盖余壁、载荷和腐蚀仍需校核。

## 面对应与流体域影响

P08 face80 与候选填料底面 BRep 相交面积 502.654824574 mm²，双侧差值分别 0 和约 -2.3×10⁻¹³ mm²：仅是面几何对应，不是密封性能。面中的 r18.2–22 区域面积约 479.910 mm² 为新肩上端面；r18–18.2 的面积约 22.745 mm² 对应杆与肩孔之间名义间隙。下游是否泄漏取决于实际填料接触与终端，不能凭这些面积定论。

新台肩侵入原代理流体 4799.096938 mm³；`P08_PACK_C02_derived_proxy_fluid.step` 是原代理流体减去此台肩的研究几何：读回为有效单实体，但体积平衡差 -0.030874 mm³，须复核布尔公差和局部拓扑，不可据此宣称体积闭合。此结果只修正局部支承占体，未补齐其他省略密封件、填料变形、实际湿面或阀盖与 FDG1 全域对应，不能直接用于求解。

理想无泄漏情景可作为明确标注的研究假设；实际密封性能未证。新流域里原 face80 已不再是完整暴露截面，不能原样沿用或直接给整个面赋壁面；需依据新拓扑重新识别内孔壁、肩面、填料接触及其余边界，并按假设明确处理。实际泄漏路径和外部压力环境仍未验证。
