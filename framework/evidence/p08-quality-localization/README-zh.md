# 固定体网格的只读质量定位

本报告没有优化、重铺、删除单元或运行流动求解。原网格 SHA256 为 904ef11aff65088f83cafb8f4dcd28f4c44c68ad72ce164ca47d3de5c9e31df8，读取前后不变。

## 结论与范围

Gmsh 日志记录 172 个 ill-shaped 单元，但没有给出其 ID。本报告不能声称已找出那 172 个单元。独立 minSICN 扫描中的分箱仅用于诊断，不是新设的验收标准：低于 0.005 为 108 个，低于 0.01 为 200 个，低于 0.02 为 1,123 个。

最差单元 ID 324416，minSICN 为 0.002528，质心约 (407.726527, 30.044706, 78.998256) mm，直接接触源面 118。最长边约 6.648 mm，最小高度约 0.006637 mm；二者比值约 1001.65。这是本报告定义的诊断比值，不是 OpenFOAM 的原生 aspect ratio。

最低 1% 共 2,306 个单元。已修导向圆柱的几何窗口内没有最低 1% 单元，保持环窗口内有 7 个；其余低质量单元主要涉及 generic / wallStep 等区域。窗口分类不是完整的有限修剪面分类，不代表其他区域已经通过验收。

## 定位证据等级

直接的“四面体边界面 → 表面三角形 → CAD 物理面 ID”映射是主要定位依据。最差 100 个单元还提供 CAD 支撑面投影候选，但包围盒和参数过滤不等于有限修剪面的精确最近距离，不能把候选排序当设计结论。

lowest-one-percent.json 保留全部低尾单元的 ID、质心、体积、边长、高度和边界邻接；summary.json 提供汇总，localize.py 可复现只读扫描。完整原始文件保存在 quality-localization.zip，原报告及其限制未被抹去。

后续应结合原生 checkMesh 的实际坏单元集合检查薄过渡区域和 wallStep，而不是仅依据一个最低质量数删除单元或全域加密。本报告不构成 CFD 就绪或工程放行。
