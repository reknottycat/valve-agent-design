# C4 基础型号研究工况与压力载荷

基础无后缀型号 **522-35.4179** 已由用户选定。本轮自主采用 **海水、−2…+50°C、0.63 MPa表压**
作为研究设计载荷包络，进一步完成真实CAD受压面映射和接口敏感性计算。
C2几何与C3接口包保持冻结；本轮没有声称原制造厂额定值、实际现场工况或制造放行已被查明。

先看 `T40/out/C4_load_study.png` 或可编辑SVG。唯一选定输入为 `T06/research_basis.json`；
来源建议及细节在 `T06/research_sources/`。本轮研究计算已通过，实际工程放行仍为HOLD。

## 1. 压力选择不再悬空，但保留准确的证据性质

[LPA原厂目录](https://lenpromarmatura.ru/downloads/LPA_catalog_sudarm.pdf#page=54)印刷第53页的
基础型号对应产品PN栏为6.3 **kgf/cm²**。[NIST换算](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b8)给出
1 kgf/cm² = 0.0980665 MPa。

| 数值MPa | 用途 |
|---:|---|
| 0.588399 | 仅当原图“Ру6”按6kgf/cm²理解时的算术敏感性 |
| 0.61781895 | 类比目录6.3kgf/cm²的精确物理量换算 |
| 0.63 | 本项目选定研究载荷，比目录换算高约1.972% |
| 1.0 | 额外静态数值超载敏感性，绝非批准的物理试验压力 |

公称等级、物理单位换算、制造厂设计压力和本项目研究假设分别登记。
0.63 MPa不声称包络未知水锤、外压、温度降额或安装外载。
参考外压取0.101325 MPa(abs)，用于明示表压/绝压边界；这不是实测场地气压。
介质温度来自原图注4，未继承−02的氯化钙低温用途。

## 2. 用实际CAD受压面计算，不再对所有工况套同一个DN面积

从C2冻结STEP导入closed和check_closed两个姿态，每个闭位流体域均有入口/出口两个独立实体。
以零体积的相对平面求交识别润湿区域，对零轴向投影的圆柱面先核对轴向，再积分
`Fz = −p × 面积 × 零件外法向z分量`。每个面及文件SHA均可追溯。
独立投影面积公式和两姿态“阀瓣＋阀杆”总压力面积守恒均通过。

下列是相对参考外压的**表压增量载荷分量**，+Z表示向上；两端压力分别相乘，不能只输入压差：

| 主研究情景 | 入口/出口MPa(g) | 阀瓣轴向分量 | 阀杆轴向分量 |
|---|---|---:|---:|
| 丝杆抵住、正向关闭 | 0.63 / 0 | +19.792 kN | 0 |
| 丝杆退开、反向止回 | 0 / 0.63 | −25.722 kN | +0.641 kN |
| 丝杆抵住、两侧均压 | 0.63 / 0.63 | −5.288 kN | 0 |
| 丝杆退开、两侧均压 | 0.63 / 0.63 | −5.930 kN | +0.641 kN |

反向止回阀瓣分量比简单`0.63×DN200面积`大约30%，来自当前研究几何的Ø228座圈外缘与干接触区域。
这不是已确定真实密封有效直径；座面压力渗入、泄漏和变形可能改变压力作用边界。
等压仍有净闭合分量，也正是干接触面积假设的后果。

**载荷分量不是接触反力或最终驱动力。** closed的阀座与丝杆两处单边接触，
仅靠合压力不能唯一分配两反力，还需重量、预紧、刚度、摩擦和接触状态。
check_closed的正向受压诊断在忽略这些项时要求负的阀座反力，不能当成可维持的静态落座工况。
四个压力级别都保留此“预期红例”，没有把它们静默当作正常止回平衡。

结果：`T19/pressure_areas.json`、`T15/load_study.json` 与 `load_cases.csv`，共20组。

## 3. 驱动与紧固的下一步现在有了定量方向

[Bornemann制造商名义表](https://www.bornemann-gewindetechnik.de/en/products/trapezoidal-threads/data/)支持
Tr36×6基本中径33、外螺纹根径29、内螺纹小径30和大径37mm。
这些是DIN103类比基本尺寸，不是原图公差等级或制造后最小根径；单头6mm导程仍明确为解释性假设。

采用相对运动反向的19.792kN水压力分量，按库仑螺旋平衡计算扭矩，并以
[Roton效率关系](https://www.roton.com/screw-university/formula-calculators/efficiency-power-screws-forward-drive/)
独立核对每转功。轴向15°半牙角先转换为法向截面角，未直接混用。

- 螺纹摩擦系数仅扫描0.03/0.08/0.15/0.25，不宣称实际润滑摩擦已测量
- 以0.15为一个情景，只有螺纹时约70.24N·m；加入36/60mm支承环均匀磨损模型、支承摩擦0.10时约117.74N·m
- 对Ø320手轮，上述模型轮缘力分别约439N和736N；未与原图辅助扳手45kgf限值直接比较，施力位置和扳手长度不同
- 低摩擦0.03情景不满足静态螺纹自锁条件。不能把“梯形螺纹”本身当成已验证防倒转措施；振动下保持还需专门设计
- 29mm名义根径上，仅该轴向载荷分量的平均正应力约29.96MPa；这不是包含扭转、弯曲、屈曲、疲劳和牙根集中后的强度通过值
- 40/54/70mm名义啮合长度的均匀投影牙面压力代理约9.55/7.07/5.45MPa。包络长度不等于实际有效啮合，未据此选螺母材料或比较厂商允许载荷

上述模型未包含最终密封预紧、填料阻力、启动力和真实支承布局。因此它是**液压力分量驱动敏感性**，
不能直接作为采购执行器额定扭矩。结果提示应优先细化轴向反力支承和保持路径，再选具体轴承/螺母。

C3三套盖接头以垫片内缘、中径、外缘作有效受压直径情景：0.63MPa下分离载荷分量约42.2–53.2kN，
较宽J8-20密封环可到58.6kN。按螺柱数量等分只是比较尺度；实际螺柱载荷、残余夹紧力、预紧和垫片应力
仍需接头刚度与密封边界计算。没有自动选定J8、J12或任何预紧扭矩。

结果：`drive_sensitivity.csv`（12组）、`joint_sensitivity.csv`（9组）。

## 4. 海水不再直接套纯水，但负温与压力效应仍需检查

根据[原作者公开论文](https://web.mit.edu/lienhard/www/papers/journal/Thermophysical_properties_of_seawater-DWT-16-354-2010.pdf)
数学关联式独立实现，并与[MIT原始表](https://web.mit.edu/seawater/2017_MIT_Seawater_Property_Tables_r2b_2023c.pdf)
9个温盐点交叉核验，未复制第三方程序源码。
20°C、假定盐度35g/kg、参考绝压0.101325MPa时，密度1024.9109kg/m³，动力黏度0.001076629Pa·s。
0/20/50°C与30/35/40g/kg的九组均通过舍入表值检查。

−2°C不在这段实现的域内，函数明确拒绝；盐度和压力也有限域门。
根据[TEOS-10冻结点说明](https://teos-10.org/pubs/gsw/html/gsw_t_freezing.html)，实际低温相态依赖组成和压力，
不能默认−2°C海水总是单相液体。常压属性也未完成到0.731325MPa绝压的压力修正。
本轮不把0°C替代成−2°C通过，不把常压关联式的精度标签变成整阀CFD误差。
