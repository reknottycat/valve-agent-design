## 文档复算

在已有Python环境中，使用已安装的python-docx、lxml和Pillow运行：

    python build_calculation_book.py

默认读取本包`sources`快照，生成`output`中的DOCX、构建摘要及独立算术复核文件。不需要CAD或求解器。该操作不会运行工程源码中的求解或CAD步骤。

若需要以新的工程证据刷新快照，在确认目标工程仓库后显式使用：

    python build_calculation_book.py --repo /path/to/project --refresh-sources

刷新只在本计算书目录中写入来源副本和文档，不修改工程仓库。新的来源并不自动使尚未完成章节获得结果，应先审查数据性质，再更新章节内容并重新逐页渲染。版本变化后应更新本说明和文档状态。

PDF可由已有Word或LibreOffice导出；本版以Noto Serif CJK SC等可用字体渲染并逐页检查。更换字体或软件版本后必须重新检查公式、分页、表格与中文字符。生成器针对LibreOffice的数学保留字解析，显式保留多字母单位、函数及下标的普通文本性质；分式、根号与上下标仍为原生可编辑结构。
