# valve-agent-design

从一张 GA 外形图出发，做一套 **AI 阀门自主设计** 的完整工程资产。

本仓库记录的是**第一台阀的完整设计过程**：图纸识读 → 参数提取 → 结构方案 → 参数化建模 →
CFD/FEA → 计算与验证 → 交接包。所有结论都标注来源与状态等级，不把假设写成事实。

## 尚未解决（重要）

设计输入有三处硬缺口，未解决前**不得冻结设计基线**：

1. **青铜牌号** —— 图纸只写「бронзовый」，无牌号。已按零件功能分配候选牌号
   （阀体 БрА10Ж3Мц2 / 摩擦副 БрО10Ф1，均有 ГОСТ 来源），
   但 **−40 °C 低温性能未查到，许用应力 [σ] 未取得**。
2. **设计压力 / 试验压力未给** —— 仅有公称压力，公称压力 ≠ 设计压力，P-T 组合编不出来。
3. **内部件几何为自主提出** —— GA 图对摆盘/阀座/铰轴零标注，
   本轮提出的拓扑是**工程判断，不是从原图还原**。

另有一处矛盾未解：图纸标题栏标「Ру 6」，而它自己引用的 ГОСТ 1536-76 压力档位里
只有「Ру 6,3」，没有「Ру 6」。该阀法兰尺寸（Ø295 / 螺栓圆 Ø264 / 12×Ø15）与标准吻合，
但压力等级的写法对不上，需要回原图或制造厂 ТУ 确认。
