| 项目 | 原图复核结果 |
|---|---|
| 机构 | 中央竖直阀杆、水平阀瓣/阀座；未见C0所称底铰轴摆盘与配重杠杆 |
| 面到面 | 明确标注600*，是参考尺寸，不是缺失值或300mm |
| Ø320* | 手轮直径，不是杠杆跨度 |
| 57* | 阀杆/手轮参考行程；自由阀瓣最大升程另列研究假设 |
| 基本型介质 | 按变型表适用海水-2…+50°C；28%氯化钙-40…+50°C属于-02适用条款 |
| 注30 | 机械防松，不是IP55/IP54 |
| ГОСТ356-80 | 压力系列标准，不是石棉垫片标准 |
| 图像摘要 | 几何页旧SHA256记录错误，重新计算并保留原始Git blob校验 |

星号尺寸依注31为参考。部分局部紧固件细节另有公差，不能概括为整张图无受控尺寸。
