## 已纠正的关键输入

| 项目 | 原图复核结果 |
|---|---|
| 机构 | 中央竖直阀杆、水平阀瓣/阀座；未见C0所称底铰轴摆盘与配重杠杆 |
| 面到面 | 明确标注600*，是参考尺寸，不是缺失值或300mm |
| Ø320* | 手轮直径，不是杠杆跨度 |
| 57* | 阀杆/手轮参考行程；自由阀瓣最大升程另列研究假设 |
| 基本型介质 | 按变型表适用海水-2…+50°C；28%氯化钙-40…+50°C属于-02适用条款 |
| 注30 | 机械防松，不是IP55/IP54 |
| ГОСТ356-80 | 压力系列标准，不是石棉垫片标准 |
| 图像摘要 | 几何页旧SHA256记录错误，重新计算并保留原始Git blob校验 |

星号尺寸依注31为参考。部分局部紧固件细节另有公差，不能概括为整张图无受控尺寸。
完整来源、变型适用性及冲突见C2/T06。厂家相似产品的材料和压力不自动成为本项目输入。

## 已验证的工作和边界

云端已实际运行CadQuery 2.7.0、FreeCAD 1.0.0、Gmsh 4.13.1及meshio。
C2主模型和多位置STEP、几何回归、明确毫米到米转换的网格均由脚本生成。
最新检查结果以各目录JSON及日志为准，不能只看成功退出码。

OpenFOAM/CalculiX另有隔离环境与标准基准输入准备，但相关审批取消后保持暂停；
本阀CFD/FEA没有被写为已经通过。网格有效、计算自洽、工程验收和实物验证分开记录。

## 本地复现

```bash
# 建立哈希锁定的CAD/网格环境，宿主FreeCAD需单独可用
PYTHON=python3.12 bash runs/20261006/CLOUD/T04/bootstrap.sh

# 核对源图和变型，从单一参数重建、验证，再生成探索用SI网格
.venv-cloud/bin/python runs/20261006/C2/T06/validate_inputs.py
.venv-cloud/bin/python runs/20261006/C2/T12/build_lift_model.py
.venv-cloud/bin/python runs/20261006/C2/T22/validate_lift_model.py
.venv-cloud/bin/python runs/20261006/C2/T23/mesh_open_domain.py
```

研究图纸脚本还使用matplotlib、reportlab和ezdxf，原生FCStd快照使用宿主FreeCAD。
STEP/FCStd是中性几何交付；参数化主数据仍是JSON与CadQuery脚本。
