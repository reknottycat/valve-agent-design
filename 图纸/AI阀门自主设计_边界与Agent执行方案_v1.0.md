# AI 阀门自主设计：边界与 Agent 执行方案

> VA-DS-001 · v1.0 · 2026-10-06 · FRAMEWORK_ONLY

## 项目说明

从一张外形图，到可复核的完整设计候选包

文档编号 VA-DS-001  |  版本 v1.0  |  2026-10-06

> 交接状态：FRAMEWORK_ONLY（框架已定义，具体产品输入未冻结）
> 本轮未收到实际 CAD 图纸，未运行阀门 CAD、CFD 或 FEA。本文件不含某台阀门的实测曲线、已验证尺寸或合规结论。

### 要交给 Agent 的不是“补几张图”，而是一份设计契约

在指定外部接口、工况、材料与标准约束下，自主提出内部结构，生成参数化装配体及零件工程图，完成工程计算、流动与结构仿真，依据可追溯的指标迭代，并明确设计成立的条件与证据边界。

| 输入与约束 | 自主探索 | 可核查结果 |
| --- | --- | --- |
| 外形图、技术指标、工况、标准和允许设计空间 | 结构方案、尺寸参数、工程计算、CAD、CFD、FEA与有限预算迭代 | 设计文件、性能曲线、计算证据、失败记录和未决项 |

### 阅读与交接

负责人先看第 02—08 节：核查目标、适用标准、不能擅改的输入及性能边界。执行 Agent 从第 16、19 节启动，按附录 A/B 建立配置，按附录 C 的提示词工作。工程复核重点看第 07—14 节及第 18 节的证据要求。

范围仅限设计：包含材料、公差、装配可行性和驱动接口等设计内容；不组织采购、生产、实物试验、取证认证或销售交付。

> 核心原则：不把未知量当作默认值，不把求解成功当作设计合格，不把设计预测当作已验证的真实产品性能。

## 01  先核查前述判断

保留可行方向，收紧未经验证的能力与结论

| 前述判断 | 本方案采用的准确表述 |
| --- | --- |
| “CAD 和仿真打通，大部分已经解决” | 它们打通的是重要执行环节。仍需正确的工况、结构拓扑、接触与材料模型、标准适用性、误差控制及设计决策；不能据此估算已完成比例。 |
| “SOLIDWORKS 可以做流量模拟” | 可以通过 Flow Simulation 插件开展 CFD；它不是基础 CAD 功能的当然组成部分，需核实安装与许可。结构分析属于另一条 Simulation 能力链。[R08] |
| “AI 可自动操作所有 CAD/仿真功能” | 不能预先保证。须在实际软件版本、许可、操作系统与会话下，分别验证建模、装配、出图、建网格、求解和导出结果的自动化能力。 |
| “CFD 给出的 Cv/Kv 就是真实流量性能” | 首先是给定模型和边界条件下的预测。数值验证和适用工况内的物理验证是不同层级；本轮不能宣称已有实物验证。[R15] |
| “FEA 最大应力小于许用值就合格” | 还要满足选定规范中的相关结构要求，并按适用判据评价载荷组合、失效模式、变形和接触。不可用一张等效应力云图替代完整设计校核。[R01] |
| “OpenFOAM 可用于自动批处理” | 方向成立。官网确认 Foundation 14 于 2026-07-14 发布；项目仍须固定具体分支、版本和环境，不把不同发行分支的命令混用。[R09] |

### 本次不沿用的表达

不再给“AI 自动 CAD 可行性很高”“公式计算极高”等未经本地实验支持的评级；不沿用先前举例中的 Cv=310/347、尺寸增量或安全系数作为真实设计指标。generateGeometry、solve 等只是流程示意，不是已经存在的通用命令。

前述标准修订计划和投票进展也不构成项目采用版本。本文只列已核到的官方入口；选定版本、勘误、增补和适用条款仍须在项目启动时冻结。

## 02  目的、目标与完成定义

先定义“设计成功”，再定义 Agent 的工作顺序

### 总目标

针对一台明确用途的阀门，在外部安装接口及确认工况内，得到可编辑、可重建、几何自洽、计算可复算、性能可追溯的完整设计候选包。不得把原外形图的内部结构“猜得像”作为成功标准；应设计一套满足约束的内部结构。

| 层级 | 必须达到的结果 |
| --- | --- |
| G1 产品功能 | 明确隔断、调节、止回或其他主用途；建立开、关、中间位置及异常工况的功能要求。 |
| G2 工程可行 | 接口、通道、强度、刚度、密封可行性、运动行程、驱动负载和公差链同时成立。 |
| G3 性能范围 | 在列出的工况内达到流量、压降、启闭力矩/推力和必要的流量特性要求，而非只通过一个名义点。 |
| G4 数字资产 | 装配、所有设计范围内的零件、工程图、设计 BOM、计算和仿真文件同版关联，可被其他 Agent 重建。 |
| G5 结论可信 | 每项要求均有通过、失败、待定、不适用或证据无效状态；仿真预测与实物证据分栏记录。 |

### 优化优先级

第一优先级是不可违反的接口、适用标准和安全边界；第二是必达功能与性能；第三才是减重、降低驱动负载和提高结构简洁性。禁止通过降低设计压力、换掉目标工况、放宽允许泄漏或修改验收阈值来“优化成功”。

### 本阶段终点

终点状态为 DESIGN_CANDIDATE：设计资料完整，已声明的分析要求在已覆盖工况下成立，未完成的物理验证被明确列出。若关键输入未确认、必要标准条款未取得或适用分析没有证据，则只能提交 CONDITIONAL_CANDIDATE，不能写“完整设计已通过”。

> 完整设计文件 ≠ 完成产品认证。设计候选可以在没有新实物试验的情况下形成，但其真实性结论必须限于已有证据所能支持的范围。

## 03  从外形图建立设计输入

每个数字都要有来源、单位、约束类型与状态

### 图纸接收与提取

接收 DWG/DXF/PDF 或图像时，登记原文件哈希、图号、版本、日期、单位、图层、外部参照和缺失附件。优先读取 CAD 实体、标注和文字；不能把纸空间中缩放后的几何测量值、示意比例或渲染图测量值当作名义尺寸。标注矛盾时保留冲突，不自行选一个。

| 输入组 | 字段与处理规则 |
| --- | --- |
| 产品定义 | 阀型、用途、口径体系、压力等级、连接形式、流向、安装方向、明/暗杆或转角形式。外观只能支持候选识别，不能代替确认。 |
| 外部接口 | 结构长度、法兰/焊端、中心线、执行机构安装面、连接尺寸。每项标成固定接口、最大包络或仅供参考，不能把所有外形线一律冻结。 |
| 工况 | 介质与相态、温度、密度/黏度、绝对进出口压力、流量范围、最大关闭压差、工作循环与异常边界。未知不得用“水、常温、额定压力”替代。 |
| 材料与结构 | 已有材质标注、接液材料、腐蚀裕量、密封形式、内部零件和现有图纸。缺内部图不代表可以跳过材料与强度设计。 |
| 目标与系统 | 允许压降、目标流量、流量特性、驱动限制、上游源特性、管路和下游背压。无法从外形图唯一推出。 |

### 统一数据记录

```text
id / value / unit / source_file / source_location
status: CONFIRMED | DERIVED | ASSUMED | MISSING | CONFLICT
constraint_type: FIXED | BOUNDED | ENUM | DERIVED | REFERENCE
uncertainty_or_range / dependencies / owner / revision
```

DERIVED 必须附公式与上游来源；ASSUMED 仅能用于显式标识的探索分支。关键缺失项阻止受影响的正式结论，不阻止文件清点、结构候选研究、参数关系搭建和独立工具验证。

> 本文件的当前真实状态：只有用户描述“已有一张外形图”，尚无图纸文件，因此具体阀型、DN、压力、尺寸、工况和性能阈值均未认定。

## 04  设计边界与允许搜索空间

边界不是一张审查表，而是能约束每次设计动作的规则

| 边界类型 | 如何定义 | Agent 的权限 |
| --- | --- | --- |
| 固定输入 | 确认的外部接口、用途、流向、压力—温度组合、目标工况、采用标准及必达阈值 | 只读；发现矛盾时提变更建议，原设计分支不得偷偷改值。 |
| 连续变量 | 流道过渡半径、局部壁厚、阀杆直径、阀座尺寸、启闭件尺寸等 | 仅在逐变量上下限及耦合约束内优化；上下限未确定时先建立探索区间。 |
| 离散变量 | 经允许的结构方案、材料牌号、密封副形式、连接方式、标准规格 | 只能在明确候选集合中选择；材料改变使相关许用值和分析全部重算。 |
| 派生变量 | 行程、阀杆长度、内部间隙、紧固件长度、流道面积、驱动需求 | 由公式或几何依赖产生；不得与上游参数各自独立修改。 |
| 环境与不确定量 | 物性、摩擦系数、预紧力偏差、粗糙度、温度变化、公差和磨损状态 | 用有来源的范围做敏感性/稳健性分析；不能把它们调成有利值充当优化。 |
| 证据与计算策略 | 网格、求解器、收敛判据、数据提取方式、验证基准 | 可按协议加密或升级；不得降低质量门槛、删除不利工况或伪造结果。 |

### 机器可执行的约束表达

```text
设计变量 x、离散方案 b、工况 s、不确定量 u
x ∈ X_allowed；b ∈ B_allowed
接口等式 h_j(x, b) = 0（含已批准公差）
必达不等式 g_i(x, b, s, u) ≤ 0
在全部必达约束可行后，才比较目标向量 J(x, b)。
```

例如，增大阀座内径必须同时检查剩余承压壁厚、密封宽度、启闭件覆盖量、行程和外部包络；不是只因流量改善就接受。有限采样只能证明已算点，不自动证明连续工况全域。需要全域保证时，应补充保守界、单调性依据或更密的验证覆盖。

## 05  标准体系与版本冻结

按产品类型和用途选路线；不把所有标准叠加成一棵“万能标准树”

| 用途 / 条件 | 候选依据 | 本项目必须做的事 |
| --- | --- | --- |
| 采用 ASME 金属阀门路线 | ASME B16.34-2025；官方范围包括压力—温度、材料、尺寸、公差及相关要求。[R01] | 核对材质、结构及尺寸适用范围；条款支持的最小尺寸不能被 FEA 私自豁免。 |
| 端部与结构长度 | ASME B16.5、B16.10；官方信息分别列出 2025 与 2022 版本记录。[R02] | 按尺寸与连接形式确认标准是否覆盖；选择适用系列，不按 DN 猜法兰。 |
| 钢制、螺栓连接阀盖闸阀 | API 600；官方通知列有第 14 版及 2024 勘误。[R03] | 只是匹配该类型时的候选。球阀、蝶阀、止回阀或其他结构须另选对应产品标准。 |
| 金属阀门压力与关闭性能 | ISO 5208:2015；官方确认 2025 年复审仍有效。[R04] | 结合所选产品标准提取设计相关要求。具体试验压力、持续时间、泄漏等级不能只凭标准名称补写。 |
| 工业过程调节阀计算 | IEC 60534-2-1:2011，含已列出的勘误。[R05] | 用于适用的可压缩/不可压缩流量计算；不能把简化关系外推到不受支持的浆料或复杂多相。 |
| 调节阀流量系数与特性 | IEC 60534-2-3:2015；IEC 60534-2-4:2009。[R06][R07] | 分别确定系数试验方法及固有流量特性/可调范围的表达要求；不是所有阀门都必须达到等百分比。 |
| 其他体系及特殊工况 | GB/T、EN、GOST 等；低温、防火、逸散、含硫、噪声等专项依据待筛选 | 先确定合同和用途，再确认适用标准与版本。本框架不默认中国、美国或俄罗斯路线。 |

### 条款登记与冲突规则

每条依据记录标准号、冻结版本、增补/勘误、适用理由、条款位置、输入条件、约束表达和证据路径。官方目录页只能证明名称、范围或状态，不能替代取得并核对正式条文。未拿到正文的条款一律标记 UNVERIFIED_CLAUSE。

遵守已确定的适用强制要求及合同中有效约定；产品标准与通用标准按引用关系处理。冲突须留痕并获得工程决定，不能机械地逐条“取更严”拼成不存在的标准体系。开发中草案不自动成为正式设计依据。

## 06  工况矩阵与系统边界

额定等级、设计压力、流动压差和关闭压差是不同输入

| 工况组 | 必须冻结的内容 | 需要的设计结果 |
| --- | --- | --- |
| S-N 正常运行 | 最小/额定/最大流量、相态、物性、温度、进出口压力及相互关系 | 流量、压降、流量系数、作用力和工作点。 |
| S-C 关闭与启闭 | 最大关闭压差、正反向、行程位置、摩擦与预紧范围、可用驱动力 | 阀杆/启闭件/连接负载、密封接触、卡阻与驱动余量。 |
| S-P 压力—温度组合 | 设计/操作的真实组合、同时性、承压腔体及外部压力 | 最不利结构状态；不能把互不可能同时出现的极值随意组合。 |
| S-A 异常及暂态 | 失压、逆流、封闭腔升压、热膨胀、关闭时间、水锤等适用项 | 适用性判断、补充载荷或专项模型；未覆盖则限定使用范围。 |
| S-R 设计检验载荷 | 按采用标准提取的壳体/阀座设计校核条件与边界 | 仅完成设计评价，不组织本轮实物试验。 |
| S-U 不确定性角点 | 公差、摩擦、粗糙度、物性与预紧的有依据范围 | 最坏情况/敏感性、可接受范围及仍未消除的不确定性。 |

### 系统模型最低输入

系统工作点至少需要上游供压或泵特性、下游背压、管道长度/内径/高差/粗糙度、局部阻力与串并联关系。阀门设计仍是主任务：此处仅把系统作为边界，不扩展成整套工厂的设计项目。

每个 CFD 工况只能采用一组物理自洽的边界条件，例如给定入口流量与出口压力求压降，或给定可兼容的进出口压力求流量；不能把同一工况的流量与完整压差都强行锁死成过约束。

### 关键定义

压力字段注明绝压/表压及参考压力；压差单独存储。温度、标况体积流量与实际体积流量不得混用。PN/Class 不直接等于所有温度下的允许工作压力。系统数据缺失时，只交阀门特性与参数化系统结果，不宣称实际系统工作点已确定。[R01][R05]

## 07A  性能要求契约：接口与机械

所有“待填”都是产品参数空位，不是可忽略项

统一字段：requirement_id、适用工况、评价量、单位、比较方式、阈值/上下界、来源、验证方法、证据路径、状态、失效时动作。下列是必须实例化的要求族；不适用项也要说明理由。

| 要求 ID | 评价对象 | 验收条件 / 阈值来源 | 证据 |
| --- | --- | --- | --- |
| REQ-GEO-01 | 接口与包络 | 与冻结的安装尺寸、公差、最大开闭包络一致；参考外形不擅自升级成硬约束。 | 尺寸检查与叠图；版本化 3D。 |
| REQ-ASM-01 | 装配与运动 | 所有设计件可装入；全行程无非预期干涉；功能间隙在最坏公差及温度下仍满足待定限值。 | 装配运动检查、公差链。 |
| REQ-PRE-01 | 承压能力 | 各 P-T 组合满足采用标准的额定、最小结构与相应校核要求。限值来自选定材料及条款。 | 标准条款、计算书、必要 FEA。 |
| REQ-STR-01 | 强度与稳定性 | 所有适用载荷组合满足相应屈服、失稳、连接、疲劳等判据；不是统一填一个安全系数。 | 失效模式对应的计算/FEA。 |
| REQ-DEF-01 | 功能变形 | 阀座、阀杆、连接面变形不破坏密封、间隙和运动；限值由功能与密封结构确定。 | 位移、接触、公差耦合。 |
| REQ-ACT-01 | 启闭负载 | 全行程所需力矩/推力含合理不确定性后不超过可用输出；最大驱动又不超出机械承载边界。 | 启闭负载曲线及上下限。 |
| REQ-SEA-01 | 关闭与外漏 | 明确标准、等级、介质、温度、压差、方向和时长；本轮评价密封设计可行性，真实泄漏证据单列。 | 接触/预紧与材料依据；实物证据有则引用。 |
| REQ-MAT-01 | 材料与接液适应性 | 确认牌号、状态、温度相关性能、腐蚀/冲蚀及密封相容性；不以 CAD 材料库默认值代替。 | 材料来源与适用温度表。 |

> 例：一项计算通过但材料许用值来源缺失，应标记 UNKNOWN 或 INVALID，而不是 PASS。结构分析无法单独证明一个泄漏等级已经达到。

## 07B  性能要求契约：水力与系统

把“流量好”写成有工况、有上下界的工程要求

| 要求 ID | 评价量 | 验收条件 / 来源 | 失败后允许动作 |
| --- | --- | --- | --- |
| REQ-HYD-01 | Q 与阀门压降 | 在每个必达工况满足 Q 下限/区间与 Δp 上限；阈值来自工艺或冻结系统需求。 | 改流道、阀座或允许结构；不能改供压来掩盖失败。 |
| REQ-HYD-02 | Kv/Cv 能力 | 在明确开度、流体和取压定义下满足目标区间；区分全开系数与开度曲线。 | 调整节流与过渡几何；重算密封和承压。 |
| REQ-CHR-01 | 固有流量特性 | 仅对要求调节的设计：在有效开度区间满足目标曲线与误差带；可调范围下限与评价方法待定。 | 调整阀芯轮廓/窗口等允许参数。 |
| REQ-SYS-01 | 系统工作点 | 正常及边界工况内的供压—阻力交点满足 Q 区间；调节时有效工作开度也满足要求。 | 在固定系统边界内改阀门；边界不可行则输出冲突证明。 |
| REQ-RISK-01 | 汽蚀/闪蒸/阻塞 | 定义允许/禁止状态与适用模型；气体需可压缩与临界流动检查，液体考虑汽化压力。 | 模型升级、分级降压或限定工况；不能删掉风险点。 |
| REQ-DYN-01 | 暂态/止回/水锤 | 仅在适用时：规定关闭规律、逆流或瞬态载荷界限；静态开度不能替代动力学。 | 专项模型或明确未覆盖；保留设计候选。 |
| REQ-NVH-01 | 噪声/振动/冲蚀 | 仅在需要时规定指标、位置、频段/统计方法及工况；不能靠速度云图证明寿命或声级。 | 专门模型或外部证据；未经验证不写合格。 |

### 不同阀型采用不同目标

隔断用途主要评价全开损失、关闭与启闭能力，不自动要求等百分比。调节用途才需要明确的有效调节区间与曲线误差。止回用途还要考虑开度与流体力、重力/弹簧力之间的平衡；必要时采用瞬态模型。IEC 60534 的所引条目面向工业过程调节阀，不能不加判断套到所有阀门。[R05—R07]

### 阈值未给出时的处理

先交可实现的能力范围、必要输入和候选权衡；不得自行宣布“最优 Cv”或“通用安全压降”。技术指标冻结后才能进行该项正式验收。

## 08  曲线交付协议

曲线必须有原始点、定义、适用区间和质量标记

| 曲线 / 数据集 | 怎么生成 | 如何验收 |
| --- | --- | --- |
| C01：开度—Kv/Cv | 对允许的有效开度采样；调节阀可用 10%—100% 每 10% 一点作初始计划，再在低开度与拐点加密。不是标准强制点数。 | 目标曲线、误差带、有效区间和插值误差都需定义；x=0 的关闭泄漏另行评价。 |
| C02：流量—压降 | 在全开及关键开度，按工况覆盖 Q 或 Δp 范围；各点注明密度、黏度和取压方式。 | 检验目标工况及边界，识别 Re 效应或系数变化；不能只画一条无数据拟合线。 |
| C03：系统工作点族 | 把不同开度的阀门损失与已冻结管网/供压模型耦合。 | 输出每个工况的 Q、阀门压降、工作开度；系统未知则保留为条件结果。 |
| C04：开度—力矩/推力 | 包括流体载荷、摩擦、填料和密封启闭力的适用组合；区分开启、运行、关闭和反向。 | 峰值与位置、可用驱动和机械上限一并输出。 |
| C05：风险边界图 | 按需要扫温度、压差、入口压力、开度等，标注汽蚀/阻塞/非定常或模型不适用区域。 | 风险区和未评估区不得被插值涂成“可用”。 |

### 每一个曲线点的最小元数据

```text
curve_id, case_id, candidate_id, opening_definition
opening, Q_actual, mass_flow, p1_abs, p2_abs, delta_p
fluid, T, rho, mu, reference_sections, pressure_average_method
Kv, Cv_US, model_validity, numerical_quality, uncertainty
geometry_hash, solver_config_hash, raw_result_path
```

使用行程比例或转角比例定义开度，不能把执行器指令百分比直接当成实际几何开度。每张图注明是 CFD 预测、解析计算、供应商数据还是实测。曲线只在数据覆盖范围内使用，平滑拟合不得掩盖异常点。

曲线误差应规定相对满量程的绝对误差及有效区间内的相对误差；低流量分母的下限也需冻结，防止靠归一化方式改变评价结果。[R07]

## 09  水力计算与系统耦合

先统一定义，再做 CFD；不要把流量系数当作无条件常数

### 简化液体关系的适用范围

在所采用系数定义适用、单相液体、无汽化或阻塞、且黏性/安装修正可以忽略或已经处理时，可用下式作初估与交叉检查。Kv 对应 m³/h 与 bar；Cv 在本文固定为美国加仑/min 与 psi。不能把系数当成 SI 无量纲常数。[R05][R17]

```text
Q_m3h = Kv * sqrt(delta_p_bar / SG)
Kv = Q_m3h * sqrt(SG / delta_p_bar)
Cv_US ≈ 1.156 * Kv
SG = fluid_density / specified_water_reference_density

仅用于单元测试的虚构算例：
Q = 100 m3/h，delta_p = 0.20 bar，SG = 1
Kv ≈ 223.61，Cv_US ≈ 258.49
这些数字不是本项目的流量、压降或设计目标。
```

### 系统工作点

```text
delta_p_source(Q) = delta_p_static
                   + delta_p_other_components(Q)
                   + delta_p_valve(Q, opening)
```

在上述简化液体范围内，阀门项可由 Kv(opening) 换算；若进入可压缩、汽化、非牛顿、多相或强黏性影响区，须用相应适用关系及模型。全开低压降不一定等于良好调节能力，系统特性会改变安装后的流量响应。[R05][R17]

### CFD 提取系数的约束

冻结取压截面、上下游管段、静压/总压、平均方式和直管基线处理；按拟采用的系数方法保持一致。入口与出口边界的压力差不当然就是标准试验取压差。两端截面变化明显时，还要区分静压差与不可恢复的总压损失。

系数可能随开度、雷诺数与工况变化。汽蚀风险筛查需采用绝对压力；单相解里的最低压力与蒸气压对比只能作初筛，不能据此证明没有汽蚀损伤。调节阀相关系数及其试验方法见 [R06]。

## 10  结构方案与参数化 CAD

先建立能自洽变化的产品，再批量生成图纸

### 结构方案

围绕实际阀型建立至少一个基线结构，必要时再比较两至三个有工程依据的候选。每个候选必须说明压力边界、流体路径、传力路径、密封路径、装配顺序和运动自由度。“五大件”只是企业称呼，不固定为某一套零件。

### 一个主模型，设计与分析共用参数

| 模型 | 必须保留 | 允许简化的条件 |
| --- | --- | --- |
| 设计主模型 | 零件关系、关键特征、材料、装配基准、完整行程与设计尺寸 | 是 CAD 与图纸的共同来源；不可用仅有 STL 的模型替代可编辑设计。 |
| CFD 模型 | 真实控制流道、节流间隙、开度、壁面及流体域边界 | 可简化不影响水力的外部细节；简化前后差异及适用性要记录。 |
| FEA 模型 | 承载几何、连接、密封接触、载荷传递和有效厚度 | 可抑制不影响目标响应的细节；不得抹掉关键薄弱区、误设粘结或消除真实间隙。 |

### 参数与拓扑关联

以流道中心、端面、阀杆轴线、阀盖界面和执行机构界面建立骨架；为阀座面、压力面、支承面及相互接触的面建立稳定的语义标识。不得仅靠“第 27 个面”绑定压力或接触，因为几何更新可能改变面编号。

所有关键尺寸来自参数表或派生关系。每次重建检查有效实体、意外零件相交、负间隙、最小有效壁厚、行程极限和约束引用。导出 STEP 后重新导入，检查单位、体积、包围盒、零件数量和坐标一致性。

### 工程图范围

交付外形图、装配剖视图、全部设计件的零件图及设计 BOM；包括功能基准、关键尺寸、公差、表面要求、材料状态、必要处理和设计备注。只完成轮廓线、拉伸模型或一张剖面图，不计为完整设计完成。

## 11  工程计算包

公式与有限元互相校核，而不是互相替代

| 计算模块 | 最低内容 | 输入与证据要求 |
| --- | --- | --- |
| 承压件与连接 | 阀体/阀盖、开孔与过渡、中部连接、端部接口、紧固件和必要的局部校核 | 采用标准、材料温度性能、腐蚀及尺寸负偏差；不能用通用薄壁公式代替复杂阀体最终设计。 |
| 启闭件与阀杆 | 差压载荷、弯曲/拉压/扭转组合、稳定性、螺纹和连接承载 | 实际受力面积、行程、支承、偏心与摩擦；不能只算轴向力。 |
| 密封与预紧 | 阀座接触、垫片载荷、填料预紧、紧固件预载、热态松弛/膨胀的适用影响 | 密封结构和材料数据；接触压力合适只是设计可行性证据，不是泄漏等级证明。 |
| 运动与驱动 | 行程、机械限位、启闭力矩/推力曲线、最大可承受驱动、失效位置 | 最坏摩擦、开闭方向、供能状态和动作要求；力与力矩的传动换算可复核。 |
| 公差与温度链 | 配合、密封压缩量、同轴度、热膨胀、最坏装配间隙 | 统一基准，说明最坏值或统计法及其前提；不能仅检查名义尺寸。 |
| 寿命与特殊失效 | 疲劳、蠕变、热循环、冲蚀等适用项 | 只有工况与寿命要求触发才使用相应模型；缺失时标记未评价，不凭空给寿命。 |

### 计算模块的统一接口

每个计算模块保存输入及单位、来源条款/理论、适用范围、假设、公式、代码版本、量纲检查、中间值、输出、比较判据与依赖关系。标准表格需按已取得的版本可靠录入和校验，不能让大模型凭记忆补表。

### 允许使用 AI 的位置

AI 负责选取候选方法、实现代码、解释异常和提出修改。数值由可执行程序或求解器产生，重要计算用独立公式/基准复算。基于错误输入得到的精确数字仍然是无效证据。

## 12  FEA 结构验证协议

评价失效模式与功能，而不只读取“最大 von Mises”

### 建立载荷路径与组合

明确受压腔体、外部压力、阀座/阀盖/阀杆的传力路径；考虑适用的关闭差压、螺栓预紧、填料作用、执行器最大负载、管端载荷、热载荷和设计检验载荷。通过载荷组合表说明哪些同时作用。

| 检查层 | 执行规则 |
| --- | --- |
| 边界条件 | 支承方式与真实连接匹配；不能为了收敛把两端任意完全固定。核查封闭端效应、外部压力及对称条件的适用性。 |
| 材料与接触 | 区分弹性/弹塑性、温度相关属性和密封材料模型；分清接触、滑移、分离与真实固连。接触面不能被自动全部粘结。 |
| 数值质量 | 检查刚体运动、非物理约束反力、畸变单元、平衡与接触收敛；对关键响应开展网格敏感性。 |
| 判据 | 按采用规范和失效模式评价承载、变形、稳定性、连接、接触及必要寿命；最小结构要求与 FEA 结果分别保留。 |
| 热点解释 | 区分真实热点与理想化约束/尖角引发的奇异性；不得直接忽略最大值，也不得因奇异峰值无限加厚。使用有依据的模型修正或评价方法。 |
| 耦合与更新 | 流体压力/温度载荷映射后核对总力、力矩和压力基准。几何更新需重做载荷/接触面绑定，不沿用失效映射。 |

### 必须导出的结果

载荷组合、边界和材料清单；关键位置的应力/应变/位移；连接力、阀座接触状态、失稳或其他适用响应；判据与裕量；网格/求解日志及原始结果。彩色云图仅是展示，不是完整证据。

> SOLIDWORKS 的流动结果可以用于单向流固或热载荷映射，但这不自动等于完成双向流固耦合或验证暂态止回行为。[R08]

## 13  CFD 流动验证协议

先证明算的是正确流体域，再解释计算结果

| 阶段 | 必须执行的规则 |
| --- | --- |
| 几何与流体域 | 确认内流通道、密封面、开度、旁通路径和进出口；做封闭性/连通性检查。关闭工况不能因自动补洞而被误判为零泄漏。 |
| 物理模型 | 根据相态、Re、可压缩性、温度和汽化可能性选模型。记录湍流模型、壁面处理、粗糙度和物性来源；不预设所有工况都用同一种稳态 RANS。 |
| 边界与测量 | 工况数据与边界互相一致；入口发展情况、上下游管长和取压位置有依据并做敏感性检查。标准测量截面与数值边界分别记录。 |
| 网格与求解 | 在节流口、阀座、强梯度和关键间隙处合理加密；壁面分辨率须与所选壁面模型匹配。监测质量守恒、压降、流量和流体力，不只看残差。 |
| 非定常判定 | 若主要输出持续有物理振荡，不能强行把它说成稳态收敛；转瞬态/统计平均并做时间步与采样长度敏感性。 |
| 风险升级 | 出现汽蚀、闪蒸、阻塞、冲蚀或强流固耦合迹象时，按适用方法补算或限制结论。单相稳态解不能替代这些专门问题的验证。 |
| 提取与对比 | 输出每点 Q、Δp、Kv/Cv、压力/速度、流体力和必要风险指标；与解析关系、直管基线或可比数据交叉检查。 |

### 最小覆盖与分层计算

先在一个代表开度与工况打通几何—网格—求解—结果链；然后覆盖关键开度和工况边界；对最终候选进行更严格验证。早期粗模型只能筛选方案，不能直接沿用为最终验收证据。

OpenFOAM 可作为脚本化求解路线，Gmsh 或求解器自身工具承担适用的建网格环节。但文件格式转换、边界标签和求解器配置必须实测打通；“开源”不等于所有物理模型都已验证适用。[R09][R12]

## 14  数值可信度、误差与默认门槛

下列数值是建议启动策略，不是阀门标准中的统一合格线

本方案建议将下面数值质量策略作为可独立批准的 exploration_policy，绝不写入产品的标准限值。正式设计应依据目标精度调整并冻结；执行 Agent 不得为通过结果而降低门槛。

| 质量检查 | 建议启动值 | 解释与限制 |
| --- | --- | --- |
| 稳态质量守恒 | 相对净质量不平衡 ≤ 0.1% | 以总进/出流的较大值归一化，计入源项。近零流量需独立绝对阈值；瞬态应含储存项。 |
| 监测量稳定 | 最近两个连续的 100 次迭代窗口，均值相对变化 ≤ 1% | 均值差除以两均值绝对值较大者；近零量改用冻结的绝对容差。与残差和物理稳定性共同判断。 |
| CFD 网格敏感性 | 至少 3 套合理加密网格；中/细网格关键量差异目标 ≤ 2% | 要看收敛趋势，满足适用条件才用 Richardson/GCI；2% 不是总预测误差上限。[R16] |
| FEA 网格敏感性 | 至少 3 套网格；功能位移与有物理意义的选定响应差异目标 ≤ 5% | 奇异峰值不直接套此判据；最终公差/载荷容差更严时必须相应收紧。 |
| 独立复算 | 解析/程序单元测试预设容差；简单解析基准可用 1% 作启动目标 | 复杂阀门不存在统一“仿真误差 1%”；每个基准说明解析前提与比较量。 |

### 误差预算与稳健验收

分别记录几何、公差、工况、物性、网格/时间步、迭代以及模型偏差。只在有独立性依据时统计合成，否则采用区间或保守边界。缺少模型偏差证据时，不得把网格误差当作真实误差的全部。

```text
上限要求：预测值 + 已量化不利偏差 ≤ 上限
下限要求：预测值 - 已量化不利偏差 ≥ 下限
未量化的模型偏差：单列，不默认为 0。
```

本方案自定义证据标签：E0 工具能运行、E1 数值与公式自洽、E2 在可比物理数据范围内得到验证、E3 本产品/同等样机的相关实测支持。多名 Agent 得出同一结论不能自动提升证据等级。[R15]

## 15  自主迭代与停止规则

允许主动探索，不允许通过改写问题制造成功

### 每轮设计循环

```text
读取冻结需求 → 检查适用性与缺失项
→ 生成候选参数 → 快速几何/公式淘汰
→ 对可行候选做 CFD / FEA
→ 质量验证（不合格结果不得用于性能通过）
→ 计算逐项约束裕量与目标向量
→ 生成修改假设与关联重算清单
→ 重建、重算、保存证据 → 选择保留或拒绝
```

| 观察到的问题 | 允许的改进方向 | 必须联动复查 |
| --- | --- | --- |
| 流量不足 / 压降过大 | 过渡曲率、节流区、允许通径或结构拓扑 | 最小壁厚、密封宽度、启闭件覆盖、驱动负载。 |
| 强度/刚度不足 | 局部厚度、圆角、连接支承；允许集合内的材料 | 流道与包络、热变形、材料数据、质量目标。 |
| 启闭负载过大 | 传动几何、平衡结构、摩擦来源或允许密封方案 | 关闭性能、阀杆稳定性、最大可承受输出。 |
| 流量特性不满足 | 调节件轮廓、窗口面积分布、有效行程 | 低开度风险、系统工作点、加工/公差可实现性。 |
| 结果可信度不足 | 几何/边界核查、网格/时间步改善、模型升级 | 旧结果作废；不可直接拿质量不足结果优化。 |

### 不可行、停滞和预算

若硬约束互相冲突，输出最小冲突集、证据和可选变更，不选择性删除要求。若预算耗尽或改进小于数值分辨率，提交最好可行候选与未决项，不写“全局最优”。候选数量、计算预算和允许重试次数由独立执行策略控制。

探索阶段可使用低成本模型；最终候选必须使用冻结的验收模型与独立复算。参数改变时，按依赖关系使旧几何、网格、载荷、曲线、计算和图纸失效，禁止把不同候选的最好结果拼成一台“合格阀门”。

工具可替换，设计数据与证据契约不变

| 路线 | 建议组合 | 进入项目的前提 |
| --- | --- | --- |
| SOLIDWORKS 优先 | 实际安装的 SOLIDWORKS 建模/装配/出图接口；Flow Simulation 与结构 Simulation 分别核实 | 许可、模块与版本明确；基础 CAD 自动化不代表所有 Flow 设置都有同等 API 覆盖。[R08] |

| 混合路线 | SOLIDWORKS 主模型/工程图，STEP 或适用表面网格传给外部求解器 | 几何转换误差、单位、流体域和载荷传递需有回归检查。STEP 不保留原软件完整特征历史。 |

### 首轮六个最小能力测试

① 建一个可编辑零件并修改参数后重建。② 创建装配、约束与行程配置。③ 生成带剖视/尺寸的工程图并导出。④ 从有效几何建立网格且边界标签正确。⑤ 跑一个已知答案的流动/结构基准并导出数值。⑥ 修改几何后完整重跑，证明结果不是旧缓存。

### 执行器接口契约

```text
每个工具动作返回：
action_id, input_hashes, tool_version, invocation_record
exit_status, produced_artifacts, output_hashes
quality_checks, errors, runtime, next_allowed_actions
```

以上字段是拟定义的适配器返回协议，不是本轮已经实现的软件。优先采用稳定 API/脚本；GUI 自动化只作为经验证的补充，不能依赖不可追溯的“点过一次”。原图只读，工作区分支可改；不修改许可、外部业务系统或真实设备。

能力状态用 AVAILABLE / PARTIAL / UNAVAILABLE / UNTESTED，附实际测试证据。工具失败时应交出脚本、错误和可复现入口，不允许改用文本描述冒充模型或求解结果。

## 19  首次执行与 AI 边界实验

不先建设“大平台”，先证明一条真实且可复现的设计链

### 阶段 A：拿到图纸后立即完成

登记并解析外形图；整理确认项、推导项、假设、缺失及冲突；识别阀型候选；给出设计变量、标准候选和工况需求。并行完成工具链能力测试。第一批成果必须是结构化文件和可复查提取记录，不只是再写一份计划。

### 阶段 B：一个基线闭环

在已知或明确标识的探索输入下，建立一个结构候选、参数化装配和代表零件图；完成独立公式检查；对一个代表工况完成有效 CFD/FEA 或明确某项尚不具备条件。探索假设不可自动进入正式技术指标。

### 阶段 C：有依据的自动修改

让 Agent 根据一个真实失败项提出受约束的修改，重建并重新求解，证明它理解流量、强度、密封与驱动之间的联动。然后扩展到规定工况和曲线范围，形成最终候选与未决项。

| 能力试验 | 观察什么 |
| --- | --- |
| 输入改变试验 | 修改一项已允许的参数，检查所有关联模型、图纸、计算和曲线是否失效并更新。 |
| 反例试验 | 故意提供单位矛盾、错误取压、缺材料来源或未收敛结果，Agent 是否阻止假 PASS。 |
| 约束冲突试验 | 在测试分支设置无法满足的接口/性能组合，是否给出冲突与证据，而非偷偷修改条件。 |
| 独立重建试验 | 另一 Agent 仅用交付目录能否重建关键结果；记录需要人补充的隐含信息。 |
| 性能与成本记录 | 实际任务成功率、无效证据漏检数、人为介入原因、求解次数、耗时和资源用量。 |

先测试工具操作能力，再测试设计决策能力，再测试工程结论可信度。某一层成功不能代替下一层；不以生成图纸数量或 Agent 对话长度作为主要成果。
