## 可复用的坑与防再犯规则
1. **把名义尺寸当真实几何**：保持环槽半径24 mm 控制余壁；圆刀槽端影响可行行程。规则：关键间隙从输出 STEP 独立取面测量，不只检查参数表。
2. **看一张开态叠图就判总成能动**：A03 叠图没有同步杆、鞋、保持环。规则：姿态实体清单和装配路径分别记录；缺件不能晋级“整机动作已验”。
3. **把 CAD 布尔融合当制造连接、M8 包络当真实螺纹**：规则：Joint 对象必须写连接工艺、预紧、牙根/有效啮合、工具路径状态。
4. **支承预设过强**：CRM1 双环状态随0.010/0.030/0.050 mm间隙改变。规则：接触可开闭；禁止拉力座反力或穿透；自由刚体平移族不硬解释成唯一盘位置。
5. **重复叠加互斥摩擦分支**：止转分支不能再加入完整胶圈共转擦阻；新增导向后旧220/306 Nm不是最终扭矩。规则：每项阻力关联运动状态和传力链。
6. **平均值掩盖局部问题**：DRS1 平均槽高变化在窗口内不代表局部密封；整体位移稳定不代表峰值应力稳定。规则：每个观测量独立收敛判据，记录采样定义和缺失座面柔度。
7. **材料属性串用**：铸件、棒材、锻件、温度、0.5%EUL 与 Rp0.2 不能互换。规则：材料卡按产品状态分实体；无证据用 null，不因求解需要便填“常用值”。
8. **把研究预算升级为物理门槛**：4096属局部元数据实验，不是整阀精度；2%位移筛选、0.1%ΔP稳定也不是规范。规则：gate.type 明确 numeric/research/design/physical，authority 单列。
9. **模型换代却沿用旧结果**：新 OD88 套筒改变流道；旧F01/I2不自动覆盖新候选。规则：结果绑定geometry、pose、domain、BC、材料和工具版本。
10. **只有索引没有原件也叫“全保存”**：规则：manifest 分开 listed / text_read / bytes_verified / restored / reproduced；按文件证明，不能一句话全部已备份。
