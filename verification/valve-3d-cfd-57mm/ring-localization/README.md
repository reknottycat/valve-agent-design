# 57 mm 整阀：缺陷定位和受限修补实跑

固定输入 `open57-ring-v22-si.msh.gz` SHA-256 `5e3a72898fe148b5fcfcd38bd0d7b7e5636439ae144ada446f7a2982b3e58a81`，同一 Foundation 11、同一完整质量检查，无压力求解。两个私有 Kaggle CPU 任务：[原网格定位](https://www.kaggle.com/code/zhenhefu/dn200-v22-native-localization)、[修补后整阀检查](https://www.kaggle.com/code/zhenhefu/dn200-ring-repair-check)。

`native-baseline.zip` 含原生单元/面集合、毫米坐标与实际任务源码。`independent-replay.zip` 含在同一四面体网格上按 Foundation 11 的 primitiveMeshTools::cellDeterminant、polyMeshTools::faceWeights 独立复算的坐标和局部试验。四面体的相邻面法向中心距离比等于两侧四面体体积比。CI 将两份坐标逐点核对到 0.00001 mm（比较数值输出，不代表实际制造精度）。原生编号与源网格编号不同，不按行号对齐。

4,657 个低行列式单元中 4,213 个只通过两个内部面连接其他单元。该检查只计内部或耦合面的面积法向，两个方向不可能张成三维，所以继续按同样方式沿棱边细分不保证解决问题。最大一簇是约 r=112.4 mm、z=21.96 mm 的六段环边，共 2,502 个；r 以 (300,0) mm 为轴心。不能据此认定零件设计错误。16 个低权重面是另一种失败，其中 12 个处于导向缝附近。

只替换这 2,502 个四面体：不动原三角面、边界、几何或外部节点；每个四面体插入一个内部点，连成四个子单元。从 35 个内部位置中按最差子单元行列式选择；简单取中心仍有 963 个子单元不通过。`native-candidate.zip` 是修补后真实整网格原生日志、失败集合与实际执行脚本，不是压力算例。原网格保留不变。

| 单元数 | 1,291,975 | 1,299,481 |

局部原因得到验证，但整阀仍不放行。简单把这种修补复制到其他区域还可能增加非正交面；需要分别处理其余边角和急剧变化的相邻单元体积，同时观察非正交性，不能只优化单项或降低标准。未证明网格无关性、实物压降或产品是否合格。
