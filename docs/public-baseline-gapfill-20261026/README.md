## 基线决策

1. **原 R1 只读保留。** 固定版本 `aa80b87b6ee9617754101a238f70bec99393ad9a` 的研究假设、历史状态与证据不覆写。原图 57* 是阀杆/手轮参考行程；R1 将瓣固定在 57 mm 是独立研究姿态，不是原图已证明真实全开。
2. **另开公开参考候选轨道。** 优先审查 Perlwitz 017960 DN200 直通 SDNR 作为相近机构参照，有无弹簧、具体订货配置和工况尚待选择。IL SHIN F7353 和 MESON SDSL 仅分开的对照；后者为螺杆截止对照，不自动具备相同止回动作。[厂家候选卡](public-reference-cards.md)
3. **不拼接“混合阀”。** 不把 Perlwitz 材料、IL SHIN 孔表、原图压力标记及 MESON 内部机构拼成一套已经验证的阀。厂家 DN200 / PN10 / JIS5K 不证明原阀同物，也不能变更原 Ру6。
4. **按公开参数约束设计空间，不宣称唯一反演。** Cv/Kv 可限制整体通流能力；不能唯一确定内部流道、公差、材料或密封预紧。Re=10 诊断不能直接套常系数湍流平方律。见 [参数反推边界](parameter-constraints.md)。

## 推荐审查顺序

先核 [缺口账本](gap-ledger.md) 的身份/配置与压力门，再定材料及内部尺寸，随后建立公差链、载荷和验收规范。只有这些门足以支持相应问题，才进入获授权的建模和求解。读者可用 `python -B validation/validate_package.py` 检查分类、来源、单位、默认不采纳及文件完整性；这是包一致性检查，不是标准或产品验证。

[来源登记](source-register.json) 给出链接、页码/定位、修订信息与引用限制。包内只保存少量事实与原创摘要，不分发厂家整本目录、CAD 或付费标准正文，也未获得可直接复制制造的开放设计许可。
