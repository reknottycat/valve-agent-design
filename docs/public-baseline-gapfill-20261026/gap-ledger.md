# 工程缺口与最小闭合证据

公开字段已补进候选矩阵，不把“有目录数值”标成工程门关闭。以下12项均 OPEN；评审角色是建议分工，不是已承诺负责人。

| 门 | 下一步 | 最小闭合证据 | 阻塞范围 |
|---|---|---|---|
| G01 产品身份及候选配置 | 选原522变型或明确新基线；公开参照只选一个产品族，决定直通/角式、SDNR/SDSL、有无弹簧及具体BOM选项。 | 签署的候选定义、机构简图、变型适用要求与源修订。 | 全部后续模型解释 |
| G02 压力基准 | 解释原Ру6与标准/修订；分列工作、设计、最大正反向压差、瞬变、试压与绝压/表压。 | 批准的工况表、适用规范条款与原缺失时间分布协议或替代设计载荷。 | 强度载荷及试验定值 |
| G03 材料与许用值 | 建立逐件牌号、状态、制造路线、温度依赖性能、腐蚀裕量/配对和材证要求。 | 受控BOM、合法材料规范、性能/许用值来源及海水/低温适用审查。 | 强度、热配合与寿命 |
| G04 完整内部几何 | 确认座/瓣有效直径、座宽/角度、最小壁厚、杆根径/导程、导向、完整接头及真实行程。 | 可验证零件图/实测或明确标注的新设计尺寸；同版CAD与接口控制图。 | 有效面积、接触、流域真实性 |
| G05 公差及制造检验 | 制定导向/杆配合、密封带、同轴/形位/粗糙度、冷热间隙和装配公差链。 | 公差计算、全温域最坏情况/合理统计模型、加工与检验可行性。 | 接触连续性、卡滞和泄漏 |
| G06 载荷和驱动 | 由已定义有效面积和压差求压力合力，补预紧、填料与螺纹摩擦、导向损失及手轮/辅助工具力臂。 | 逐载荷工况、方向/符号、组合规则、摩擦依据和独立手算。 | 杆、螺纹、接触强度 |
| G07 公式语义与实现一致性 | 复核F-STR-002、F-FLW-001、F-DRV-002及F-FLW-002局部冲突；另核密封符号与螺纹模型。 | 合法正文定位/适用条件、单位/物理量绑定、实现与样例一致性、消费者调用链。 | 相关公式自动执行；不阻止只读检索 |
| G08 结构和接触验证 | 检查杆压扭/屈曲、螺纹承载、体盖/螺栓、座接触与热变形；明确边界和安全准则。 | 同版输入、解析基准、合适FEA、网格/接触敏感性和工程审查。 | 结构合格结论 |
| G09 密封验收 | 定义内漏与外漏分项、方向、介质、温度、压力、保持时间、泄漏限、循环与操作状态。 | 适用产品/试验标准和合同、仪器方案、实际试验记录或被接受的证据。 | 密封合格和制造放行 |
| G10 流动目标与可比基准 | 确定流量域、物性、瓣姿态、取压/参考面积、管段修正及Kv/K/CFD比较条件。 | 实际工况或明确独立研究假设；流态/汽蚀门；守恒、稳定性和敏感性证据。 | 产品流量/压降/阻力系数发布 |
| G11 平台资源与执行授权 | 核实际CAD/FluentMeshing/Fluent/结构求解器版本、可用模块和合法许可证，再定授权运行范围。 | 只读环境盘点与授权；许可条件、资源上限、输入哈希和任务目标。 | 安装、采购、模型运行 |
| G12 同版交付与工程验收 | 汇总已批准的CAD/BOM/工况/计算/模型/标准/试验及剩余风险，由负责方审查。 | 可追溯总清单与独立签审，所有工程门关闭或明确批准的豁免。 | 完整工程交付和制造批准 |

## 可以先做和仍需另行授权

在当前资料范围可继续只读核对来源、统一单位、细化参数约束和审查局部候选公式；不能因此自动选择材料、制造公差或标准。新建/修改真实CAD、购置或安装平台、运行CFD/FEA、提交上游及制造放行均不由本包触发。

完整机器账本见 [gap-ledger.json](gap-ledger.json)。公式源记录的内部问题另见 [ontology/gap-ledger.json](ontology/gap-ledger.json)，其原始状态未被改写。
