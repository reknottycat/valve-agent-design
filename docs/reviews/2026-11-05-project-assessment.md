# 阀门项目阶段评价与研究闭环优先路线

评价日期：2026-11-05。对象：无后缀 **522-35.4179，DN200 青铜止回-截止阀**。

本评价固定核对写入前 main [`6acdec261fabd4607f644752dea2071dfc29f9dd`](https://github.com/reknottycat/valve-agent-design/tree/6acdec261fabd4607f644752dea2071dfc29f9dd)，并按下文的不可变链接读取 R1、复用研究线和 C02 独立候选。它是本次阶段判断的记录，不是第二份动态方案。当前版本、任务和执行顺序仍以 [CURRENT_PLAN](../../CURRENT_PLAN.md) 为唯一入口。

**总体判断：项目已有真实 CAD、结构和局部流动成果，值得继续；来源、单位、版本和防误用护栏的成熟度，已领先于候选设计的执行与评价闭环。下一阶段最有价值的工作，是在同版输入上得到可信、可比较、能指导下一次设计变更的研究评价器，而不是继续增加 Agent、声明式任务或通用护栏。**

本次只读核对仓库正文、脚本和已有观测记录，保存评价与建议。没有重新生成 CAD、重划网格、启动 CFD/FEA、恢复求解检查点或开展实物试验；没有修改 R1、标准库、数值配置及验收限值。下述历史结果不算本次新计算，建议步骤也不表示已经实施。

## 1 已有成果应当保留并复用

项目已经越过纯概念阶段。否定全部既有工作、从头造一套系统，会丢掉最有价值的模型经验和失败证据。

- **模型与来源已有基础。** R1 分开型号、工况、研究假设和来源。AGR1 有中性 STEP 往返、实体有效性及几何量比较记录；现行方案记载实际回读 12 个有效实体。这支持交换几何和后续研究，不等于制造连接、完整 BOM、实物装拆或原生特征树已合格。[S1][S2]
- **结构和接触不是空白。** DRS1 在同几何、同载荷下做过真实阀盘两网格计算；CRM1 有自由开闭接触及独立模型交叉核验。DRS1 的整体位移/能量变化约 0.25%～0.40%，但峰应力从 185.638 升至 273.690 MPa，约增加 47.432%。必须同时保留整体稳定的成果和局部峰值未收敛的限制，不能用一个均值代表全部结构可信度。[S2]
- **流动线已有局部里程碑和真实推进。** NSC1 的 time960 局部压降稳定记录可复用，不必重复计算来制造进展。整阀研究已实际推进到 SIMPLE 状态 21。现行记录中，17→21 原始动量 L2 下降 68.47%、体积 RMS 下降 12.29%，说明数值诊断有实质收益，但不是整阀稳态证明。[S1][S2]
- **公式和来源护栏已进入一个真实读取入口。** main 的只读研究预检已调用固定标准依赖、公式/输入语义检查、法兰隔离和验收卡；state21 的选取端口重建、参考面积区分、研究物性及条件 Pa 转换已经交付。它们降低了错误解释和跨版本拼接风险，下一步应由真实评价器消费，而不是另起同功能接口。[S1][S3][S4]
- **失败结果也有复用价值。** p 松弛 0.15 的两步配对试验结论为 NOT_SUPPORTED，不支持替换当前主轨迹；这并不证明该值长期无效或 0.3 最优。该反例、旧失败和原始证据应保留，不重复执行已回答的对照。[S1]

## 2 目前最重要的事实边界

### 2.1 固定研究姿态不等于真实自由动作

R1 流动计划明确阀盘升高、阀杆回退各 **57 mm**，作为受约束的全开研究几何。它不预测自发升程、受力平衡或关闭行为；57 mm 不能直接当作产品真实自由最大升程。流动阻力优化不能绕过这一限定，直接声称止回功能或开启性能改善。[S5]

当前代理湿域省略实际密封几何。历史姿态链还列有未资格化的压缩垫片基准、间隙与口袋占液假设。理想无泄漏可以成为明确、可审查的研究假设，但不能改名为真实密封合格。[S6]

P08 C02 是一个独立的阀盖一体台肩候选。已有单一全开姿态的有效 CAD 与零正体积干涉记录，但 **D40 杆头不能穿过 D36.4 肩孔**，装拆序列和全行程仍未验。候选代理流体的布尔体积平衡差为 **−0.030874 mm³**，原 face80 已改变，需要重建边界身份。它不能直接接旧网格或旧流场，也不是所有后续研究都必须采用的基线。[S7]

### 2.2 state21 仍是层流数值诊断

R1 计划中的 Re10 工况使用约 **5.2523×10⁻⁵ m/s** 的入口面速度、D=0.2 m 和选定研究黏度定义名义 Reynolds 数。现有 state21 为 Newtonian/Stokes 层流诊断轨迹；21 是 SIMPLE 迭代端点，不是已验证的 21 秒物理瞬态，p=0.3 是无量纲松弛系数。不能用它代表常规工作流量下的整阀性能。Re10 是计划的名义定义，不是从当前离散网格通量独立识别出的产品流态。[S4][S5]

冻结 R1 计划中的 **0.5、1、2 m/s** 三点仍标记 STUDY_ASSUMPTION_NOT_RUN。核对的现行成果中没有它们已完成的同版结果；不能把计划流量、计划动压或旧 C0 的其他速度点冒充这三点的实际求解。计划未运行的历史标记也不能用来否认后来已经发生的 Re10 诊断推进，两者的时间和证据需分开。[S1][S5]

### 2.3 参考面积和取压定义决定能否比较

state21 两端各 136 个三角面的面积为 **0.03111103635738251 m²**，R1 的 DN200 圆面积为 **0.031415926535897934 m²**。同一 Q 和 Δp 下，K 随参考面积的平方变化；本例 K 增加约 **1.969617%** 只是定义变化，不能记作性能恶化或改善。[S4]

现有压差取自 x=−0.6 m / +1.2 m 的两个完整计算边界，入口 zeroGradient 用 owner-cell 压力重建，出口 fixedValue 为零；包含阀前后各 3DN 数值延长段。它不等价于标准壁面取压、总压损失或已扣除管损的孤立阀损。未知的下游测点不能外插出来，直管损失也不能凭估计扣除。[S1][S4][S5]

因此，**不能将约 116 或 118 的代理 K 与图纸液阻≤6直接比较后宣布产品 FAIL，更不能用换面积把它调整成 PASS**。研究可以先固定一个自洽、可复现的端口定义进行受限比较；产品是否符合≤6，必须另有适用方法、开度/安装/流态、实际物性、受控来源与验证证据。容量 Kv/Cv 的适用性仍 HOLD，不能由条件 Pa 换算补足。[S1][S4]

### 2.4 现有编排声明还不是可执行设计闭环

`tasks.json` 有 **43 个任务模板**，包括 T36 的候选决策和 T37 的下一轮编译。`validate_manifest.py` 实际验证静态任务字段、依赖、角色、资源池、工作区和无环性，输出拓扑层次。它没有执行调度、工程条件判定、真实 CAD/CAE、候选评价或下一轮设计；其说明也明确仍需实现这些能力。不能将“DAG 校验通过”报告为“自主设计系统已经跑通”。[S8]

main 中的旧 `C0/T23/cfd_pipeline.py` 也不能充当现行主线。本次静态读取可直接确认：[S9]

- 几何仍是旧解释下的倾斜/旋转摆盘，采用独立硬编码参数，不是当前轴向升降 R1/AGR1 基线。
- 写入的介质为水，ν=1×10⁻⁶ m²/s、默认 ρ=998 kg/m³，采用 kOmegaSST，与当前选定海水研究假设和层流诊断模型不同。
- p 字段声明为 m²/s²；若后处理读取分支成功，`pi-po` 会直接放入 `dp_pa`，再由 `to_kv` 除以 10⁵ 作为 bar，未见从运动学压差到 Pa 所需的密度乘法。这是源代码可见的单位链缺口；本次未运行它，也没有因此断言某个历史输出必定受到同样误差。
- 脚本自行调用网格与求解程序，没有接入当前 standards adapter / readiness；当前只读护栏不会自动拦截用户直接启动它。

旧脚本保留用于追溯。若未来复用其中任何实现，应先迁移到当前研究契约并独立检查单位、失败传播、边界及数值有效性，不能凭“完整流水线”标题恢复运行。现阶段真正缺失的是一条同版的 **候选参数 → CAD/湿域 → 网格/求解 → 可信评价 → 有界变更 → 再评价** 链，而非更多任务名称。

## 3 研究有效性与产品验收必须分层

当前九项产品验收仍 HOLD、工程放行 false。它们限制产品合格和制造结论，不应被扩展成所有有限研究的统一停止令。[S1][S3]

1. **研究输入层**：区分实测/图纸事实、已核来源、推导值和研究假设。可采用明确限定的材料或理想无泄漏假设来研究一个问题，但须说明结论对该假设的依赖。
2. **数值评价层**：确认当前几何、边界、单位、求解状态和观测定义，分别报告守恒、原始残差、局部尾部、稳态及敏感性。程序退出零、文件齐全、单个残差小均不能替代这一层。
3. **研究比较层**：只比较同一物理问题、同一观测定义和可接受证据质量的候选。暂时没有足够证据时返回不可比较或待补，不强行生成总分/排序。
4. **产品验收层**：材料、设计温压、自由动作、真实密封、装拆、公差、产品试验及批准依据分别闭合。未知只阻塞依赖它的结论；研究通过不能向上覆盖产品 HOLD。

重要的取舍是：停止增加无人消费的检查项，把必要检查放到实际输入和评价路径中；同时保留可见的失败与未知。产品方法合法正文或采用批准缺失时，可以继续边界明确的研究，不得把未知条款填成常用值，也不应无限重复搜索同一无正文线索。

## 4 下一阶段的建议顺序与完成标志

这些是后续路线建议，不是本次计算授权、已完成结果或新的并行看板。沿用 CURRENT_PLAN 和 M01～M08；公式/验收依据的现有优先事项继续推进，但产品待批事项不应使不依赖它的有限研究停滞。

### 第一步 固定一个可回答的问题和同版研究契约

沿用 M01/M02/M04，选择一条现有基线，固定几何/姿态/湿域/边界、物性、参考面积、取压定义、工具版本和证据位置。明确本轮究竟研究数值稳定、某局部几何效应，还是特定工况下的端口阻力；不同时混入自由开闭、密封和产品容量目标。

候选可变参数、不可改变的条件、资源预算、失效依赖和停止条件应先写明。若选择 C02，先处理其布尔差和新边界身份；不选 C02 时不强迫旧基线先完成 C02 装拆研究。**完成标志**是另一执行者能识别同一输入与假设，并知道结果可以回答什么、不能回答什么。

### 第二步 先建立一个可信评价器

沿用 M02/M03/M06/M07，在现有读取入口和原生观测经验上补执行消费者，不重新发明标准库或只读预检。评价器至少应做到：

- 接收一个固定候选和工况，检查真实可读输入、单位、几何与 patch 身份、运行环境；明确检查点是否仅被列出、已恢复或已验证可用。
- 对求解器退出、数值可信、研究可比较、产品适用分别输出状态。保留 Q、Δp、参考面积/K、原始残差、局部守恒、局部尾部和观察量变化；不得用一个绿色状态覆盖全部层级。
- 定义适合本问题的稳态窗口及网格/模型敏感性要求，注明依据和适用范围。阈值须在相应研究执行前确定，不能把历史 1%、4096 单元等预算或诊断值改称标准。
- 未收敛、坏网格、失效边界、缺失物性和不可比较的候选必须保留失败原因，不能进入正常性能排序，也不能把缺失值填零。
- 同一输入的重复读取/评价能得到一致身份与结论；失败、取消、恢复和重复执行不覆盖原证据，不把旧结果误挂到新候选。

**完成标志**是一个同版研究基线能形成可独立复核的输入、执行记录和评价结果；如果仍未稳态，能明确给出其受限结论和下一项有价值的诊断，而不是只输出 HOLD 或继续盲目追加步数。现有 state21 只读绑定是其中一部分，不是已经完成的通用评价器。

### 第三步 做少量有理由的候选比较

在评价器能支撑所选问题后，保留一个基线，选择少量参数变化或结构候选，例如基线加两个明确变体，而不是马上做大规模搜索。候选数量是研究规模建议，不是新验收门槛。每个变化先有物理理由，先做廉价几何/连通性/边界筛查，再决定是否需要受控数值计算。

比较时保持工况、姿态含义、参考面积/取压及质量标准一致。几何变化导致旧网格或面映射失效时，重新建立对应关系，不能跨版本借用有利结果。Re10 数值诊断适合回答的只是该诊断问题；不能据此完成常规流量性能排序。**完成标志**是能解释某候选为什么改善、退化或暂不可判断，以及结果是否大于当前数值不确定性。

### 第四步 完成一次评价驱动的有界迭代

根据上述比较只修改少量有依据的参数，记录为什么改、哪些资产失效、哪些证据可复用，再按同一评价定义核查。无需强求每次都“优化成功”：有证据地淘汰一条错误方向，也是闭环结果。

**阶段交付目标**是至少一轮可追踪的“变更理由 → 候选输入 → 评价 → 保留/放弃/继续”的完整记录。不要把增加分支、测试数量、追加文档或重复完成 NSC1 里程碑计作设计进展；保留 p=0.15 的失败对照，不为凑迭代重新跑它。

### 最后 再考虑代理模型和更广的 Agent 编排

只有同定义、同质量、覆盖明确设计范围的可信样本积累起来，才讨论代理模型、主动学习或大规模寻优。先保留独立验证样本和外推限制；预测值不能冒充实际求解。Agent 数量应由真实可并行工作和接口稳定度决定。错误或不可比较的数据越多，自动化只会越快放大错误。

## 5 本次评价的最终取向

保留既有 CAD、局部仿真、来源锁和失败证据，继续向前。优先补齐一个可执行、可核查、能决定下一步设计的研究评价闭环；产品验收仍按各自依据和实体证据推进。短期成功应以**是否关闭了一个具体研究问题，并据此作出可追溯设计决策**衡量，而不是以框架规模或状态变绿衡量。
